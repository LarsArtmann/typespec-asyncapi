## b) PARTIALLY DONE — uncommitted, tests FAILING

**M15 Stable template-instantiation names** — working tree holds 5 files (`src/schema-ref.ts`, `src/schema-emitter.ts`, `src/schema-generator.ts`, `src/lib.ts`, `test/compliance/template-instantiations.test.ts`).

What the probe (F15.1) actually found — **worse than unstable names, it's a dangling-ref bug**:
- `Page<User>` as a property/op-return emitted `$ref: "#/components/schemas/Page"` while `Page` was **never declared** — an unresolvable pointer in the output. (AJV doesn't catch it; the 3.1 meta-schema doesn't resolve refs.)
- Framework fact (read from `@typespec/asset-emitter` source): `declarationName()` computes speakable instantiation names as base + capitalized arg names (`PageUser`, `BoxInt32`), passes `name === undefined` for unspeakable args (anonymous models, union expressions).

Implemented so far:
- `schema-ref.ts` rewritten: `schemaNameForType()` + recursive `declarationNameOf()` mirroring the framework's naming, so `$ref` and declaration always agree.
- `schema-emitter.ts`: `modelInstantiation(model, name)` override (speakable → declare under derived name; unspeakable → inline); `modelDeclaration` now takes the `name` param; `declareModelSchema()` extracted.
- `duplicate-schema-name` warning diagnostic declared in `lib.ts`, wired in `schema-generator.ts` (catches `model PageUser` vs `Page<User>` collisions).
- 8-test compliance suite written (naming, nested `Page<Page<User>>`, enum args, scalar capitalization, op-return, unspeakable inlining, collision warning).

**Blocked on:** all 8 tests fail — `PageUser` never appears in `components.schemas`. Diagnosed root cause: `assetEmitter.emitProgram({emitGlobalNamespace:true})` only walks namespace members; instantiations living in property positions are only reached via `emitTypeReference`, but our `refOrFallback()` short-circuits on `refForNamedType()` and never lets the framework walk into the type, so `modelInstantiation` never fires. **Next move: in `refOrFallback`/`propertyToSchema`, for speakable instantiation types let `emitTypeReference` run first (creating the declaration) instead of short-circuiting to a hand-built `$ref`.** Not yet verified whether the ref change breaks other existing tests (only the new file was run).

Also partial: TODO_LIST v0.3.0 section not synced to reality (only Kafka item checked); CHANGELOG lacks explicit beta-publish notes (F3.3).
