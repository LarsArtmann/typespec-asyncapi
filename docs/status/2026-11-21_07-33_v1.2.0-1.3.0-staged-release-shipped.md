1. **Forgotten / found while writing this report:** AGENTS.md still claimed "v1.1.0 … (the last release ON npm)" and "dist-tags: all three … 1.1.0". Fixed now. Lesson: when a release lands, sweep the memory for every snapshot sentence, not only the incident paragraph.
2. **Too many predictable retries:** after the first 403 at 02:44, two more direct-publish attempts (02:52, 02:56) burned ~10 min of CI and fed ci-alert noise. The 403 class was already decisive; I should have pivoted to the staged design immediately.
3. **Dead end worth recording:** local `npm publish` from a non-TTY shell can never complete (EOTP per write; the auth URL is masked in tool output). 2FA cannot be delegated — this is a hard property, not an obstacle to engineer around.
4. **Wrong validation tool first:** raw Ajv v8 cannot load the AsyncAPI 3.1 schema (draft-07 `$ref` ambiguity). Two failed attempts before switching to `@asyncapi/parser`, which is the repo's own established path. Use the project's harness from the start.
5. **Memory churn:** the release paragraph in AGENTS.md was rewritten ~4 times in 40 minutes as facts changed. Each rewrite risked losing a still-true detail; append-with-correction would have been safer.
6. **Release symmetry left behind:** v1.2.0's GitHub release still has no tarball asset and no note that npm gained the version three hours later.

## e) WHAT WE SHOULD IMPROVE

1. Encode the release-security policy once (stage-only forever vs a future direct-publish toggle) and stop re-litigating it per incident.
2. Pre-flight the failure class before retrying CI: read the last run's error kind, decide design-level, then act.
3. Treat "human 2FA" as an architectural constraint: any step that needs it must be modeled as out-of-band, never retried from CI.
4. Test new workflows' failure paths within the same change window, not "later".
5. Append corrections to memory bullets instead of rewriting them wholesale.
6. Add a `docs/RELEASE.md` runbook with the three commands and the approval-order rule (`latest` must move forward only).
