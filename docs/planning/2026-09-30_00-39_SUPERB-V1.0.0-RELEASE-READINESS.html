The verdict

The codebase is already at 1.0.0 quality: FEATURES.md is all-FULLY_FUNCTIONAL, output is AJV-validated against the official AsyncAPI 3.1 schema, 14 examples compile clean in CI, and nothing breaking has landed since 0.3.0-beta.1 shipped to latest. What remains is (a) two decisions only the maintainer can make, (b) release mechanics, and (c) deliberately re-scoping the ROADMAP's "v0.4.0 direct-AST rewrite" as the internal-only 1.1.0.

01Findings

The verify gate was RED — nobody noticed

pnpm run verify failed on two counts: schema-emitter.ts had grown to 406 lines (oxlint max 400), and jscpd flagged a 6-line import-block clone between channel-builder.ts and operation-builder.ts (a recent auto-commit reformat recreated exactly the repetition _imports.ts was built to prevent). Both fixed this session — see Blockers.

Clean promotion path: 0.3.0-beta.1 → 1.0.0

CHANGELOG [Unreleased] contains fixes and additions only — zero breaking changes. The beta has carried the latest dist-tag for ~5 weeks. Shipping a stable 0.3.0 first would double release overhead for zero information; going straight to 1.0.0 is defensible the moment the semver commitment is made.

1.0.0 is an API promise, not a version string

Semver at 1.0.0 freezes the public surface: 30 decorators in lib/main.tsp, the EmitterOptions model, the emitted-document contract, and the @lars-artmann/typespec-asyncapi/shared subpath. The ROADMAP's direct-AST rewrite (EFv1 exit) must be re-titled 1.1.0 and constrained to byte-stable output — which the golden files already enforce.

Decision 1

Semver commitment — freeze the public API

Maintainer · ~15 min

Approve: from 1.0.0 on, the 30 decorators, emitter options, emitted-document shape, and ./shared exports change only in major versions. The direct-AST rewrite continues as 1.1.0 internals, protected by golden files and the compliance suite. Without this decision the rest of the plan is moot.

Decision 2 + ops

NPM_TOKEN rotation & stale dist-tags

Maintainer + npm registry · ~45 min

The TODO list has flagged NPM_TOKEN rotation since before the beta. Meanwhile beta still points at 0.2.1-beta and alpha at 0.0.1-alpha.2 — anyone installing @beta today gets a year-old build. Rotate the token, update the GitHub secret, then clean tags at publish time.
